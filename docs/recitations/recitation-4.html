Calibrating Income Processes from Data

In recitation 3 we studied the welfare implications of tax and transfer programs using a stylized income process. Today we’ll calibrate a more realistic income process using data from Arellano, Blundell, and Bonhomme (2018), and then evaluate the welfare effects of progressive taxation under this calibrated process.

Loading and Exploring the Data

The data come from the PSID and contain information on household income \(y\) (in dollars) over the life cycle. Let’s start by loading the data and examining some basic patterns.

Two cleaning steps matter a lot here:

  1. Trimming. A small number of household-years report income of $1 (or close to it). In logs these observations are extreme outliers: \(\log(1) = 0\) while median log income is about 11. Even a few dozen of them substantially inflate the variance of log income. We use a simple rule: drop household-years with income below $1,000. This removes only a few dozen of the roughly 19,000 observations.
  2. Units. We measure income in thousands of dollars. This has no effect on variances or covariances of log income, but it matters for the model: the asset grid below is also in thousands of dollars, and the two must be in the same units.
d = @chain CSV.read("../data/abb_aea_data.csv", DataFrame) begin
    @subset :y .>= 1000          #<- trimming rule: drop incomes below $1,000
    @transform :y = :y ./ 1000   #<- income in thousands of dollars
    @transform :logy = log.(:y)
end;

The function load_psid in income_tools.jl performs exactly these steps. Exercise: re-run the analysis below without the trimming step and see how much the variance of log income and the estimated persistence change.

Calculating Autocovariances

To understand the persistence of income shocks, we need to calculate the covariance of income at different lags. The code below constructs forward lags and calculates covariances (forward_lag is also saved in income_tools.jl).

# construct forward-lags
function forward_lag(d, l, var)
    d_lag = @chain d begin
        @select :person :year $var
        @transform :year = :year .- l
        @rename $(Symbol(var,"_",l)) = $var
    end
    d = leftjoin(d, d_lag, on=[:person,:year])
    return d
end

d = forward_lag(d, 2, :logy);
d = forward_lag(d, 4, :logy);
d = forward_lag(d, 6, :logy);

Calibrating an AR(1) Process

Now suppose that income in the model follows an AR(1) process:

\[ y_{it} = \mu_{t} + \varepsilon_{it} \]

where:

\[ \varepsilon_{t+1} = \rho \varepsilon_t + \zeta_{t+1}, \quad \zeta_{t+1} \sim N(0, \sigma^2_\zeta) \]

We can construct the residuals \(\varepsilon\) by first de-meaning by age. We take lags as well:

d = @chain d begin
    groupby(:age)
    @transform :eps = :logy .- mean(:logy)
end

d = forward_lag(d, 2, :eps);
d = forward_lag(d, 4, :eps);
d = forward_lag(d, 6, :eps);

Recall that:

\[ \text{Cov}(\varepsilon_t, \varepsilon_{t+s}) = \rho^{s}\text{Var}(\varepsilon_{t}).\]

This means that there are a multiple ways to estimate the persistence parameter \(\rho\), using different orders of lags.

There are also multiple ways to estimate \(\sigma^2_{\zeta}\). The simplest way is to assume that \(\varepsilon\) is in its stationary distribution which gives:

\[ \text{Var}(\varepsilon_{it}) = \sigma^2_{\zeta} / (1 - \rho^2) .\]

Below is code to calculate the covariance at different lags and estimate \(\rho\) as the mean of three alternative estimators.

cov_lag = pairwise(cov, eachcol(d[!,[:eps,:eps_2,:eps_4,:eps_6]]),
                    skipmissing = :pairwise)[:,1]


# Estimate ρ from the ratio of covariances at different lags
ρ_est_1 = sqrt(cov_lag[2] / cov_lag[1])  # (Cov(t,t+2) / Var(t))^(1/2)
ρ_est_2 = (cov_lag[3] / cov_lag[1])^(1/4)  # (Cov(t,t+4) / Var(t))^(1/4)
ρ_est_3 = (cov_lag[4] / cov_lag[1])^(1/6)  # (Cov(t,t+6) / Var(t))^(1/6)

ρ = mean([ρ_est_1, ρ_est_2, ρ_est_3])

println("Estimated persistence: ρ = ", round(ρ, digits=3))

# Given ρ, we can back out the innovation variance
σ_ε = sqrt(cov_lag[1])  # Unconditional SD
σ_ζ = σ_ε * sqrt(1 - ρ^2)  # Innovation SD

println("Unconditional SD: σ_ε = ", round(σ_ε, digits=3))
println("Innovation SD: σ_ζ = ", round(σ_ζ, digits=3))
Estimated persistence: ρ = 0.897

Calibrating Progressive Taxation

We need to choose \(\lambda\) to ensure budget balance: average net income must equal average gross income. Since initial shocks are drawn from the stationary distribution \(\pi^*\), the distribution of \(\varepsilon\) is \(\pi^*\) at every age. But mean income \(\mu_{t}\) changes with age, and with a progressive tax the same \(\lambda\) cannot balance the budget at every age: a \(\lambda\) chosen for 25-year-olds would take resources away from higher-earning 45-year-olds. So we choose a separate \(\lambda_{t}\) for each age, and let net income depend on age:

\[ \tilde{y}_{t} = \lambda_{t}y^{1-\tau},\qquad \lambda_{t} = \frac{\sum_{y}\pi^*(y)\,y}{\sum_{y}\pi^*(y)\,y^{1-\tau}}\ \text{evaluated at age-}t\text{ incomes}.\]

# Solve for stationary distribution
pi_star = solve_steady_state(p.Π)

# Choose progressivity
τ = 0.2

# Solve for λ_t at each age
λ_t = [solve_lambda(τ, exp.(income_grid[:, t]), pi_star) for t in 1:T]

# Check budget balance at every age: average net income / average gross income
budget = [dot(pi_star, progressive_tax.(exp.(income_grid[:, t]), λ_t[t], τ)) /
          dot(pi_star, exp.(income_grid[:, t])) for t in 1:T]

println("Tax progressivity parameter: τ = ", τ)
println("Range of λ_t over the life cycle: ", round.(extrema(λ_t), digits=3))
println("Net / gross income, min and max over ages: ", round.(extrema(budget), digits=6))

Welfare Decomposition

Following recitation 3 (and the notation from Lecture 2), we decompose the welfare gain \(1+\omega\) into an insurance component \(1+\omega_{I}\) and a redistribution component \(1+\omega_{R}\), with \(1+\omega = (1+\omega_{I})(1+\omega_{R})\):

(;σ, β) = p

# Certainty equivalents by initial income state
cbar0 = cert_equiv(model0.V[:, 1, 1], p)
cbar1 = cert_equiv(model1.V[:, 1, 1], p)

# Average certainty equivalents
Cbar0 = dot(pi_star, cbar0)
Cbar1 = dot(pi_star, cbar1)

# Utilitarian welfare
W0 = dot(pi_star, model0.V[:, 1, 1])
W1 = dot(pi_star, model1.V[:, 1, 1])

# Decomposition
ω = (W1/W0)^(1/(1-σ)) - 1
ω_I = Cbar1 / Cbar0 - 1
ω_R = ((W1 / V_cert(Cbar1, p)) / (W0 / V_cert(Cbar0, p)))^(1/(1-σ)) - 1

println("\nWelfare Decomposition:")
println("=" ^ 50)
println("Total welfare gain (ω):         ", round(ω*100, digits=2), "%")
println("Insurance component (ω_I):      ", round(ω_I*100, digits=2), "%")
println("Redistribution component (ω_R): ", round(ω_R*100, digits=2), "%")
println("\nVerification: (1+ω_I)(1+ω_R) = ", round((1+ω_I)*(1+ω_R), digits=4), " ≈ ", round(1+ω, digits=4))
