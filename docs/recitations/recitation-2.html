Welfare Implications of Income Risk

In class, we concluded our section on trends in inequality by thinking about the implications for welfare and policy. Today we’ll use a life-cycle savings model to study the welfare implications of different models of wage risk.

Model

Let’s assume that individuals live for \(T\) periods. They face an income process that follows:

\[ \log(y_{it}) = \mu_{t} + \varepsilon_{it} \]

where

\[ \varepsilon_{it} = \rho \varepsilon_{it-1} + \zeta_{it},\ \zeta_{it} \sim \mathcal{N}(0,\sigma^2_{\zeta}).\]

We assume a single risk-free asset with a rate of return \(r\), so that the model can be phrased recursively:

\[ V_{t}(a,y) = \max_{a^\prime}\left\{u(y + a - (1+r)^{-1}a^\prime) + \beta \mathbb{E}_{y'}V_{t+1}(a',y') \right\} \]

with \(V_{T}=0\).

We assume that utility \(u\) is of the CRRA type, so we can write the function as:

utility(c,σ) = c^(1 - σ) / (1 - σ)
utility (generic function with 1 method)

Note that \(\mu_{t}\) is the mean of log income and can evolve with the age \(t\) of the agent, but this life-cycle profile in wages is known. \(\varepsilon\) is the unknown component of income and the source of risk in the model.

Approximating the income process

There are a number of methods for approximating the AR(1) process for income outlined above using a discrete state Markov process. A popular version is Tauchen’s method. The code below is a function to produce a transition matrix \(\Pi\) and a grid of values that approximates the variance and autocovariance of an AR(1) process.

using Distributions

function tauchen(N, ρ, σ)
    # Unconditional standard deviation of the process
    σ_y = σ / sqrt(1 - ρ^2)

    # Create the grid
    y_max = 3. * σ_y
    y_min = - 3. * σ_y
    grid = range(y_min, y_max, length=N)

    # Step size
    step = (y_max - y_min) / (N - 1)

    # Initialize transition matrix
    Π = zeros(N, N)

    # Standard normal distribution
    d = Normal(0, 1)

    # Fill in the transition matrix
    for i in 1:N
        for j in 1:N
            if j == 1
                # Probability of transitioning to the lowest state
                Π[j, i] = cdf(d, (grid[j] - ρ * grid[i] + step/2) / σ)
            elseif j == N
                # Probability of transitioning to the highest state
                Π[j, i] = 1 - cdf(d, (grid[j] - ρ * grid[i] - step/2) / σ)
            else
                # Probability of transitioning to intermediate states
                Π[j, i] = cdf(d, (grid[j] - ρ * grid[i] + step/2) / σ) -
                         cdf(d, (grid[j] - ρ * grid[i] - step/2) / σ)
            end
        end
    end
    return collect(grid), Π
end
tauchen (generic function with 1 method)

This is going to produce a matrix where \(\Pi[j,i]\) contains the probability of moving to state \(j\) when currently in state \(i\).

Solving the Model

This model can be solved almost identically to the infinite horizon version. We can start by writing a function to solve the maximization problem given a point in the asset and income grid.

function solve_value(ai,yi,V,p,t)
    (;σ,β,Π,r,asset_grid,income_grid) = p
    a = asset_grid[ai]
    y = exp(income_grid[yi,t])
    vmax = -Inf
    amax = 0
    for ai_next in eachindex(asset_grid)
        a_next = asset_grid[ai_next]
        c = y + a - a_next/(1+r)
        if c>0
            @views v = utility(c,σ) + β*dot(Π[:,yi],V[:,ai_next,t+1])
            if v>vmax
                vmax = v
                amax = a_next
            end
        end
    end
    return vmax,amax
end
solve_value (generic function with 1 method)

With this function in hand we can then write a function to iterate over each grid point and calculate \(V_{t}\) given \(V_{t+1}\):

function iterate_value_function!(p,V,A,t)
    for ai in axes(V,2), yi in axes(V,1)
        v,a_next = solve_value(ai,yi,V,p,t)
        V[yi,ai,t] = v
        A[yi,ai,t] = a_next
    end
end
iterate_value_function! (generic function with 1 method)

And finally we can solve the model by doing backward induction from \(T\) down to the first period.

function solve_model(p)
    (;T,Π,asset_grid) = p
    K_a = length(asset_grid)
    K_y = size(Π,1)
    V = zeros(K_y,K_a,T+1)
    A = zeros(K_y,K_a,T)
    for t in reverse(1:T)
        iterate_value_function!(p,V,A,t)
    end
    return (;V,A)
end

The stationary distribution

To compare welfare across economies we need to know where people start. We will assume that the initial draw of \(\varepsilon\) comes from the stationary distribution of \(\Pi\): the distribution \(\pi^*\) that satisfies \(\Pi\pi^* = \pi^*\). In words, if the population is distributed according to \(\pi^*\) today, it will still be distributed according to \(\pi^*\) tomorrow. Linear algebra tells us that \(\pi^*\) is the eigenvector of \(\Pi\) associated with the eigenvalue equal to one (rescaled so that it sums to one):

function solve_steady_state(Π)
    vals, e = eigen(Π)
    k = argmin(abs.(vals .- 1))   # eigenvalue closest to one
    v = real.(e[:, k])
    return v ./ sum(v)
end

Calculating welfare effects

Let’s assume that everyone starts off with no assets, and then consider the welfare effects of differences in \(\rho\). In particular let’s let the persistence of \(\rho\) decline and see what happens.

We need to be careful here. If we lower \(\rho\) but keep \(\sigma_{\zeta}\) the same, the unconditional variance of \(\varepsilon\), \(\sigma^2_{\zeta}/(1-\rho^2)\), also falls. We would then be changing two things at once: how persistent shocks are and how much total risk there is. To isolate the role of persistence, we hold the unconditional variance fixed at its value when \(\rho=0.9\) and adjust \(\sigma_{\zeta}\):

\[ \sigma_{\zeta}(\rho) = \sigma_{\varepsilon}\sqrt{1-\rho^2},\qquad \sigma_{\varepsilon} = \frac{0.1}{\sqrt{1-0.9^2}}.\]

σ_ε = 0.1 / sqrt(1 - 0.9^2)    #<- unconditional SD of ε, held fixed
ρ2 = 0.45                        #<- move ρ from 0.9 to 0.45
egrid2,Π2 = tauchen(5,ρ2,σ_ε*sqrt(1-ρ2^2))
income_grid2 = [μ+egrid2[i] for i in 1:5, t in 1:T]
p2 = (;p...,income_grid = income_grid2,Π = Π2)
model2 = solve_model(p2)
pi_star2 = solve_steady_state(Π2)

Consumption equivalents

Values are in arbitrary units (“utils”). How can we convert them to something interpretable? One option is to think about a consumption equivalent: the percentage increase in consumption, in every period and every state, that would make someone in one economy as well off as in another.

Let \(W = \sum_{y}\pi^*(y)V_{0}(0,y)\) be expected lifetime utility for someone who starts with zero assets and draws initial income from the stationary distribution. Since each economy has its own \(\pi^*\) (and, in general, its own income grid), this average is the right object to compare. The consumption equivalent \(\omega\) solves:

\[ \mathbb{E}\left[\sum_{t=0}^{T-1}\beta^{t}u((1+\omega)c_{t}) \Big| \rho = 0.9\right] = \mathbb{E}\left[\sum_{t=0}^{T-1}\beta^{t}u(c_{t}) \Big| \rho = 0.45\right] \]

where expectations are taken over the initial draw from \(\pi^*\) as well as over future shocks. Since \(u((1+\omega)c) = (1+\omega)^{1-\sigma}u(c)\) with CRRA utility, this solves out to:

\[ 1+\omega = \left[\frac{W(\rho = 0.45)}{W(\rho = 0.9)}\right]^{1/(1-\sigma)}.\]

(;σ,β) = p
W1 = dot(pi_star, model.V[:,1,1])
W2 = dot(pi_star2, model2.V[:,1,1])
ω = (W2 / W1)^(1/(1-σ)) - 1
println("Consumption equivalent of moving from ρ = 0.9 to ρ = 0.45: ", round(100ω, digits=2), "%")
Consumption equivalent of moving from ρ = 0.9 to ρ = 0.45: 4.0%

Who gains the most?

Because we held the unconditional variance fixed, both economies use exactly the same income grid (check egrid and egrid2). This means we can also compare people who start at the same initial income \(y\). The consumption equivalent conditional on initial income solves the same equation without averaging over \(y\):

\[ \omega(y) = \left[\frac{V_{0}(0,y ; \rho = 0.45)}{V_{0}(0,y ; \rho = 0.9)}\right]^{1/(1-\sigma)} - 1 \]

cev = (model2.V[:,1,1] ./ model.V[:,1,1]) .^ (1/(1 - σ)) .- 1
plot(exp.(μ .+ egrid), 100cev, marker = :circle, legend = false,
    xlabel = "Initial income", ylabel = "Consumption equivalent (%)")
println("Lowest initial income:  ", round(100cev[1], digits=1), "%")
println("Highest initial income: ", round(100cev[end], digits=1), "%")
Lowest initial income:  30.2%
Highest initial income: -18.3%

Individuals who begin at the lowest level of \(\varepsilon\) gain a lot from lower persistence: their bad luck is less likely to last. Those who begin at the top lose, since their good luck is also less likely to last. Note that this state-by-state comparison is only meaningful because the two grids coincide; if we had changed \(\rho\) without adjusting \(\sigma_{\zeta}\), state \(i\) would correspond to a different income level in each economy.
